Exam: TV Program Recommendation
Task
Use the SWEET.TV competition data to produce a ranked Top-5 list of TV programs for each test user.
Implementation
● Implement at least two methods: Content-Based Filtering (CBF), Association Rules, Matrix Factorization (CF), or Personalized PageRank.
● Connect viewing logs with the program schedule to construct user–program interactions. Explain your matching rule and treatment of
missing program IDs.
● Compare methods using the same temporal validation split, candidate pool, and evaluation protocol.
● Include a popularity baseline as a reference; it does not count as one of the two required methods.
● Your final submission may use a single method or a hybrid strategy. Evaluate each selected method individually before combining them.
● Use the provided program metadata, but do not use future user viewing behavior for training.
Business & Algorithmic Analysis
Which recommendation strategy would you select for SWEET.TV, and why?
● Select two users and justify your selection. Use the same users across all implemented methods.
● Show each method’s Top-5 with program IDs, titles, and categories. Compare the recommendations with the users’ viewing histories and
program attributes.
● Explain how and why your selected methods differ, and what those differences imply for the user experience.
● Justify your final strategy using validation performance, computational cost, and specific recommendation examples.
● Discuss limitations and failure cases supported by your results. No live A/B test or demonstrated revenue impact is required.
